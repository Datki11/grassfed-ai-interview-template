# Grassfed AI Interview: Support Ticket Overview

This is the starter code for the Grassfed technical interview. The same exercise is available in four languages, so you can work in the one you're most comfortable with:

| Folder | Language | Entry point |
| --- | --- | --- |
| `typescript/` | TypeScript | `main.ts` |
| `python/` | Python 3 | `main.py` |
| `java/` | Java 17+ | `Main.java` |
| `csharp/` | C# (.NET 8) | `Program.cs` |

**Start with `BRIEF.md` in your language's folder.** It explains the exercise.

During the interview, your interviewer will open this exercise for you in a shared online editor, so you don't need to install anything. Running `main` prints which checks pass.

## Running it locally (optional)

| Language | Command (from the language folder) |
| --- | --- |
| TypeScript | `npx tsx main.ts` |
| Python | `python3 main.py` |
| Java | `javac -d out *.java && java -cp out Main` |
| C# | `dotnet run` |

A fresh copy prints `0 passed, 6 failed`. That's expected, because the functions haven't been written yet.
